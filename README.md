# e-plantShopping

Paradise Nursery is an online houseplant shop built with React and Redux Toolkit.

## Features
- Landing page with company intro and "Get Started" button
- Plant listing in 3 categories, 6 plants each
- Add to Cart (button disables once added)
- Shopping cart with quantity controls, delete and totals
- Live cart count in the navbar

## Tech Stack
React, Redux Toolkit, Vite
